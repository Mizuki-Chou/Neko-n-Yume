# 🐱 猫と夢 - Neko n' Yume ✨

> 猫咪与梦想的相遇之地 🌙

**猫と夢 - Neko n' Yume** 是一个 Minecraft 猫咪养成系统插件。

在这里，玩家可以与自己的猫咪伙伴相遇、成长，并一起探索这个方块世界。

每一只猫咪，都将拥有属于自己的故事。 🐾

---

## ✨ 特点

- 🐱 猫咪伙伴系统
- 🌱 猫咪养成与成长
- 💫 独特的互动体验
- 🎀 持续开发中的更多玩法

---

## 🛠️ 开发信息

使用：

- Java
- Gradle Kotlin DSL
- Paper API

支持：

- Minecraft Java Edition 26.2+
- Paper
