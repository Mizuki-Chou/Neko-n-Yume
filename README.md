# 🐱 猫と夢 - Neko n' Yume ✨

> 猫咪与梦想的相遇之地 🌙

**猫と夢 - Neko n' Yume** 是一个面向 Minecraft Java Edition 的猫咪养成与互动插件。

玩家可以与属于自己的猫咪伙伴相遇、培养、互动，并陪伴它们一起成长。每一只猫咪都拥有独立的属性、性格与成长轨迹，也可以通过技能、战斗、礼物与各种互动逐渐形成属于自己的故事。 🐾

---

## ✨ 核心特色

### 🐱 猫咪伙伴系统

每只猫咪都是独立存在的伙伴，拥有自己的身份与数据。

* 独立猫咪数据
* 猫咪名称与身份
* 猫咪品质
* 猫咪性格
* 猫咪心情
* 猫咪饥饿度与好感度
* 猫咪等级与经验
* 喵力与喵阶
* 行为模式
* 持久化数据

### 🌱 猫咪成长

猫咪会在陪伴与互动中不断成长。

* 喂食获得经验
* 抚摸与互动提升好感
* 等级成长
* 喵力积累
* 喵阶提升
* 根据成长阶段解锁更多能力

### 💫 性格与心情

不同的猫咪拥有不同的性格，并会对成长与互动产生影响。

猫咪的状态不仅仅是数字，而会影响它们与玩家之间的相处体验。

### 🎀 技能系统

猫咪可以学习不同类型的技能。

目前包含：

* 普通技能
* 稀有技能
* 独特技能
* 梦幻技能
* 主动技能
* 被动技能
* 技能槽
* 梦槽
* 技能刷新
* 技能冷却
* 战斗技能效果

部分特殊技能还会拥有独特的战斗机制与效果。

### ⚔️ 猫咪战斗

猫咪不仅是陪伴者，也可以成为玩家的战斗伙伴。

* 自动寻找敌人
* 猫咪攻击
* 技能释放
* 战斗冷却
* 猫咪虚弱机制
* 特殊复活机制
* 与技能系统联动

### 🌙 猫咪光环

当猫咪陪伴玩家时，可以根据猫咪自身的成长状态提供不同的辅助效果。

随着猫咪成长，可以逐渐解锁更多光环能力。

### 🎁 礼物系统

猫咪会在满足条件时为玩家带来礼物。

礼物系统会结合：

* 猫咪心情
* 喵阶
* 随机概率
* 礼物等级
* Minecraft 物品
* 喵丹

让长期陪伴猫咪获得更多回报。

### 🧪 喵丹系统

喵丹拥有不同品质，并可以用于猫咪成长相关玩法。

目前包含：

* 普通
* 不凡
* 稀有
* 史诗
* 传说

不同品质拥有不同的属性与显示效果，并支持自定义模型数据。

### 🖥️ GUI

插件提供猫咪信息与技能相关 GUI，让玩家能够直观查看：

* 猫咪状态
* 成长信息
* 技能
* 技能槽
* 相关操作

## 🎯 设计理念

Neko n' Yume 并不希望猫咪只是一个拥有额外属性的 Minecraft Entity。

我们希望每一只猫咪都能成为：

> **一个真正会成长、会陪伴玩家，并拥有自己故事的伙伴。**

玩家与猫咪之间的关系不是一次性的。

从相遇开始，到成长、互动、战斗，再到漫长的陪伴——

**每一只猫咪，都将拥有属于自己的故事。** 🐾
